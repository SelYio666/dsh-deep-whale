# 架构说明

## 1. 为什么是单机

早期版本用了「主机推理 + 副机哨兵」两台机器。实践下来那三件事
（每 30 分钟潜意识提炼、每 2 小时热榜、每日快照）总共只占 **< 20MB 内存、< 0.1% CPU**，
完全没必要为它多养一台服务器。

于是把它们收进 `whale-daemon/scheduler.py` 一个进程：

| 原副机任务 | 现在 | 周期 |
|---|---|---|
| `subconscious_learner.py` | `job_distill()` | 30 分钟 |
| `fetch_hot_news.py` | `job_hot_news()` | 2 小时 |
| `sync_backup.sh` + 快照 | `job_maintain()` | 每日 04:00 |
| （新增）深海梦境 | `job_dream()` | 每日 03:35 |

好处：路径统一、没有 SSH 互信密钥、Windows 本机也能挂。

---

## 2. 进程与职责

```text
DSH 进程（宿主机运行时）
 ├─ dsh-onebot-patched   协议层：OneBot v11 ⇄ DSH 会话
 └─ dsh-whale-policy     策略层：人设 / 记忆 / 情绪 / 玩法 / 渲染

whale-console/server.mjs  控制台：读 JSON、读写 brain.db、代理 memory-core、发消息
whale-daemon/scheduler.py 后台：提炼 / 热榜 / 日记 / 维护
memory-core（可选）       检索内核：SQLite FTS5 + 图谱
```

关键约束：**控制台与调度器不直接改 DSH 的会话**，只读写 `data/` 下的状态文件，
所以任何一个进程挂了都不影响聊天主链路。

## 3. 状态文件

| 文件 | 作用 | 读写者 |
|---|---|---|
| `data/state/memory.json` | 各会话记忆、印象签、好感、糖果、心潮、荷尔蒙、日记、核心记忆球 | 策略层、控制台、调度器 |
| `data/state/brain.db` | SQLite：记忆原子、实体、关系、向量、life_events | memory-core、调度器、控制台 |
| `data/state/neural-ring.json` | 神经星环的召回脉冲日志（环形缓冲 80 条） | 策略层写、控制台读 |
| `data/state/group-history-cache.json` | 群聊公共时间线持久化（重启秒恢复） | 协议层 |
| `data/state/owner-tools.json` | 主人工具状态：提醒、好友申请草稿、告状本 | 策略层、控制台 |
| `data/self/persona.txt` / `style.txt` | 人设与输出风格 | 用户编辑、控制台编辑 |
| `data/self/sticker-catalogue.json` | 表情包元数据 | 用户维护 |

**并发安全**：
- `memory.json` 用「临时文件 + `rename`」原子替换，`0600` 权限；
- Node 侧有 `mtime` 内存热缓存：同一轮 8 次读只落盘 0 次，外部进程改动后毫秒级感知重载；
- `brain.db` 开启 `journal_mode=WAL` + `busy_timeout=5000`，备份前强制 `wal_checkpoint(TRUNCATE)`，
  避免只拷主库导致页不一致。

## 4. 群聊上下文的两难与解法

**两难**：

1. 全群共用一个上下文 → 群友 A 说「我同学帮我抽了 4 个金」，10 秒后群友 B 只发一句「大肥鱼」，
   模型会把 A 的事安到 B 头上（张冠李戴）。
2. 严格按人隔离 → 群友 B 接着 A 的话说「他给你的那个我看了」，模型完全不知道「他」是谁（断片）。

**解法**：Session 仍按人隔离（各自的长期记忆互不污染），
但**每轮额外注入一段「本群公共现场时间线」**，且把机器人自己的回复也实名入列：

```text
【本群公共现场时间线（按时间先后排列）】
👥 [同群群友] 甲(1001)：我同学帮我抽了4个金
🐋 [你(鲸鱼)刚才回复「甲」]：这手气…下次让他帮你买彩票吧
👉 [当前对话人本人] 乙(1002)：那个我看了，真离谱
（💡 准则：1. 对方提到上面某人或接着话茬聊 → 必须结合时间线自然接上，不要装失忆；
       2. 对方只是单独逗你 → 只回应他本人，别把别人的经历安到他头上。）
```

同时：

- 只把**当前说话人这一句**喂给记忆/梗库/情绪模块（旁人发言不写进他的档案）；
- 时间线持久化到磁盘，重启后 6 小时内的现场仍在；
- 每轮在 `【当前消息】` 正上方钉一个**真实北京时间**，压住「顺着上一句口误报错时间」的自洽偏见。

## 5. 情绪与状态机

```text
一次输入
  ├─ 神经递质四维   多巴胺 / 催产素 / 去甲肾上腺素 / 血清素（0–99）
  ├─ 心潮五轴       思念 / 嘴硬 / 玩心 / 委屈度 / 分享欲（0–100）
  ├─ 心情精力       心情 -1~1、精力 0~1（半衰趋向基线）
  └─ 临时胶囊       糖果盒：N 轮后自动失效
        ↓
  组装「导演耳语」（只在相关时触发，避免每轮都念设定）
        ↓
    注入 system prompt（约 150–400 token）
```

设计原则：
- **不主导判断**：情绪只影响语气与长度，不影响事实正确性；
- **有上限**：所有数值 clamp，避免极端值把角色变成另一个人；
- **有半衰期**：不回弹成「恒定开心」；
- **可关闭**：糖果盒、心潮、读心术都可从配置关掉，关掉后她回到基础人设。

## 6. 图形渲染管线

`fun_plugins.mjs` 与策略层通过 `subprocess` 调用 Python：

```text
Node（判断触发 + 组织数据 JSON）
   ↓ spawn（PYTHON_BIN）
visual_cards.py / quote_card.py（Pillow 渲染）
   ↓ 写出 PNG 到 data/media/whale-stickers/
Node 用 onebot_image 发送（路径白名单校验）
```

要点：

- **字体链**：`文泉驿 → Noto CJK → 微软雅黑/黑体 → 苹方`，跨平台不出现豆腐块；
- **头像缓存**：7 天有效，单次超时 2.5s，网络抖动时降级用旧缓存（避免画 8 人关系图卡 15s）；
- **字体限制**：文泉驿没有 SMP emoji（🏆🃏🔍 会变方块），图卡里只用 BMP 符号 `★ ☆ ◆ ◇ ● ◎ ▲ ▼ ♥`；
- **白名单**：所有生成的图必须落在 `STICKER_DIR` 内，否则拒发。

## 7. 安全边界

| 边界 | 做法 |
|---|---|
| 控制台 | 无密钥返回 401；根路径返回 404 隐藏指纹；媒体文件按文件名白名单 |
| 密钥 | 只从 `whale.config.json` / 环境变量读，`data/` 与 `*.env` 全部 gitignore |
| 工具面 | QQ 会话侧禁用 subagent / workflow / schedule / 文件系统 / 配置类工具，只留聊天与媒体 |
| 记忆写入 | 明显敏感串（密码 / 密钥 / 银行卡 / 身份证等）直接拒收 |
| 认主 | 只认配置里的 `ownerQq`，群名片、头衔、口头自报一律不作为依据 |
| 路径逃逸 | 本地图片只接受 `DATA_DIR` / `MEDIA_ROOT` 之内 |
